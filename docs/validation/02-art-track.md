## A0：同方向、同场景概念检查

在共同 layout 中制作两张微差异候选，只调整模块化设施的轮廓、明暗和材质密度；数量、位置、镜头、时间段与 UI 占位相同。参考作品截图不得作为本项目资产。

第一张正常白昼总览，不用落日、大雾、电影景深和宏大城市替代指挥可读性。候选应保留着陆器、运行阵列、施工阵列、加工、补能维修、三种机器人、拟整平坡地与矿点。

交付：带“概念，非实机”标记的同场景候选、生成/修改记录、差异说明。图像工具用于开发期；Codex 没有对应图像能力时给出设计简报并标 BLOCKED，不伪造已经生成。外部图像 API 支出未获批准不得调用。

验收：所有者选择在已确认方向内更合适的造型语言。只确认概念，不因此通过材质预算、模型质量或性能。

## A1：同位置的变化与故障语言

对同一视点表达四阶段：原始坡地→整平施工→建成运行→矿点被挖开。再表达正常工作、回充、零电停机、零耐久待回收、拖运、维修。

交付：对照图、状态清单、各状态对应的真实字段/事件。不能仅靠灯色区分故障；用姿态、附件/载荷、图标与短标签协同，关闭生成台词仍能辨认。

验收：正常指挥距离能指出土坡哪里改变、矿点是否挖过、设施是否工作、机器人在做什么。不以原画近景放大截图掩盖正常缩放下看不清。

## A2：最小三维资产包

T0 给出版本与导入接口后制作：一台可动驮运（有载荷与拖运连接点）、太阳能与加工两类设施、可变坡地区域与矿点状态。筑垒/望山首轮可用清楚标记的代理体；报告区分真实完成资产与占位。

建议 Blender 源文件与 GLB 交付，具体工具合法可用且导入已验证才采用。统一米制尺度、锚点、朝向、占地、状态名称；可显示附件不代表自动新增救援规则。

记录三角面/材质/纹理/动画/LOD/碰撞与导航代理预算、来源许可、资源 hash。预算由正常镜头与 T 实测共同确定，不从其他游戏画面猜一个“行业通用数”。

所有工作状态由 T 的状态桥驱动，A 不复制库存、耐久、时钟或另写完成计时器。工作动画不是生产算法。坡地/矿点必须有实际几何变化，贴花只作补充。

## A3：真实场景可读性验收

把样件放入 T 工程，用相同 fixture、真实任务和状态拍摄。交付一段正常镜头录制与同位置前后截图，显示选择、建设、负载、充电与拖运维修；关闭生成台词再检查一次。

只使用标准视口与声明的质量档。低档可以减少装饰，不隐藏地表结果、机械故障和运输事实。记录细杆闪烁、机体遮挡、地形跳变、状态误读；真实问题进入修订，不用追加说明文案掩盖所有画面问题。

验收重点：所有者愿意长期观察；不读大段说明也知道工作在推进；完成建设确实改变了地方。真人意见由真人给出，AI 图像评价只能提出检查建议，不能代签。

## 出口与停止条件

A0 方向不合适：在既定两款参考内调整，不扩资产库。
A2 不能满足导入/可读性：停在样件，不批量制作。
A3 漂亮但依赖大量效果才看清：先修轮廓、层次和状态，不把机器门槛抬高来“解决”。

A 的完成不等于技术通过；最后进入 [联合证据闸门](04-evidence-and-freeze.md)。
