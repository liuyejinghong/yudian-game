## 当前建议，不冒充已确认

Godot 4 .NET＋C# 为首选验证候选；本地独立模拟与版本化存档为架构建议；llama.cpp 为部分模型运行候选；Blender → GLB 为资源路径建议。

地形首批采用有限局部改造，不直接做任意体素世界。返航使用“约 10% 常态参考＋当前路线／环境／可用补能点的动态安全预算”，是建议实现；本地选择器比较合法方案，精确能耗与安全边界由规则校验。未知突变仍可能造成停机，不通过故意让 AI 忽视已知条件制造挑战。

Mac 首发先验证引擎实际 MetalFX 路径、原生输出和回退；Windows 后续评估 DLSS／XeSS；FSR 按具体版本与后端验证。超分和帧生成不替代 CPU、导航、规划、模型与存档优化。官方依据见 [专项调研](../engineering/upscaling-and-renderer-evaluation.md)。

## 待样张或实测后核定

U01 原创美术样张和资产比例；U02 相机与渲染配置及超分模式；U03 引擎／.NET／原生依赖具体版本；U04 地形方法与导航更新；U05 本地规划／分类／文本模型；U06 最低硬件与规模预算；U07 磨损、维修、救援装备与载荷、零电补能方式、不可恢复失败及是否报废；U08 API 商业接入和许可；U09 正式 EA 内容量、日期和价格；U10 环境增耗倍率、返程安全余量、充电后重新出工条件和风险授权方式。

零电／零耐久的停机结果及零耐久回收维修不再列为未决。所有者最新消息末尾“游戏场景平缓”未给出完整附加规则，不扩写成事件频率或难度承诺。

这些未知项不要求所有者凭空选技术参数。执行者应给实测、方案取舍与主推荐；对产品感受与风险规则由所有者签字。

## 已被替代的提案

浏览器优先、Phaser 主框架、32px 像素、Windows 先发、远程模拟、AI 只做远期台词、持续作业作为自动化上限、必须五分钟首夜和必须新手受损，均不得从旧文档恢复成当前要求。

新增生存风险不是取消安全开局，新增地表改变不是批准无限地形系统。资源包中的“创建私有新仓库”是仓库创建前历史流程；现在使用所有者已经创建的公开 yudian-game，不再重复建库或改变可见性。

## 变更方式

改变已确认产品定位、平台、权限或离线底线需新决定；改变候选技术应有最小复现、性能证据和迁移代价。微调文案、动画帧数与数值按版本和回归纪律处理，不把每个参数都写成永不变化。

历史快照永不就地改写；当前主文档更新版本或明确补充优先关系。所有条目指向真实反馈或结果，不把“未做”“后置”“被方案替代”记成“已修复”。本次新增 B01–B08，与原 A01–A24 一起共 32 个需求验收场景，均不是本轮已跑游戏测试。
