2026-10-05｜PROPOSED，全部新包未派发。关联[里程碑](milestones.md)、[事实契约](contracts.md)、[验收矩阵](acceptance.md)。DT-* 是规划 ID，实际状态仍在产研 TODO。以下拟新增路径是写入归属建议，不要求预建目录或迁移已有效代码；READY 时先检查当前仓库，存在等价能力就复用并冻结实际路径。

**输入与步骤：**建立平移／旋转／缩放和可调范围；射线选择有 ID 的对象；以合法性查询显示固定尺寸但可选位置的作业区，先预览再提交；目标卡显示执行者、阶段、原因、取消；对象和目标互相定位。鼠标是主入口，不把玩家操作变成 JSON 表单。

## DT-E02｜固定整平到有限可选区域作业

**归属：**`Main.LevelJob.cs` 及必要的建设适配；地形核心仅对有明确需求的接缝小改。GLM 可做冻结后的纯选区／站位计算，不能自行改变提交语义。

**步骤：**把固定位置变为已授权有限区域参数；按当前采样／边界规则产生候选；选具备施工能力的可用工人和不占地的工位；仍要求真实到场、贴地、有效工作；提交前重验版本、权限和占用，提交后等物理验证。D1.0 可保留直线可达的有限范围，但必须明确拒绝／说明绕障未支持，不能假装已寻路。

**验收：**不同合法位置均走相同路径；非法范围不改地形；已有平地不增加无用版本；工人暂停／离位不累积有效工作；取消已提交改造保留，未提交候选释放；版本冲突不静默扩大范围。连续三秒仅是旧工程门槛，不能未经设计变成所有生产／施工的通用耗时。

## DT-E04｜统一暂停与最小磁盘存档

**目标／执行：**D1.0；GAME-SAVE；Codex 定边界，GLM 可做冻结 codec。前置 C01/E02；不把内存 Current 或性能 CSV 当存档。

**归属：**拟 `prototype/scripts/SimulationTime/`、`Persistence/` 的指定子件；Main 暂停／恢复接线由 Codex。

**输入／步骤：**保存 schema 版本、配置身份、模拟时间、实体 ID／位置、权威高度／表面、当前单任务／有效进度和已提交标记；不保存引擎对象指针、运行期锁或 wall-clock 收益。正常暂停停止移动／工作；地形投影锁与用户暂停分别管理，不能通过解锁地形解除用户暂停。

**验收：**工作中和完成后保存退出，重载不重改地形或重复完成；按单任务合同恢复剩余工作并重新检查到场，不凭存档坐标跳过物理验证；写入失败不覆盖上一有效档；旧版本／损坏文件明确拒绝或回退，不悄悄新开局；关闭应用不补算。

**联调：**世界先恢复，重新构建投影，物理确认后才允许运行；E01 显示保存成功或失败。C02 实际跨进程重开，而非仅序列化 round-trip。

## DT-E05｜六资源定义、矿量／库存账本与预留

**目标／执行：**D1.1 起；GAME-RESOURCES；Codex 权威提交，GLM 定义与纯函数。前置 C01 的本阶段物料合同，可与 E06/A04 并行，不需等本地模型。

**归属：**拟 `Resources/Definitions/`、`Resources/Queries/` 为 GLM 独占；`Resources/Core/` 交易、授权和持久化接缝由 Codex。

**输入／步骤：**铁矿、铜矿、铁料、铜料、结构件、线缆及明确的不可自产开局组件；定义可调配方、设施需求与保障耗材。区分矿内剩余、现场库存、仓储、机器人载荷、预留、在途和已承诺产出；每批实物只有一个保管位置。预留不等于扣除或已送达。

**验收：**需求10、未预留库存3、确属本目标的在途4时净缺口为3；属于另一目标的在途不得抵扣。取货从来源转入载荷而不生成一份副本；请求重试不重扣；取消只释放本目标不再需要的承诺；整数／有限量边界无负值、溢出或 NaN。示例数值仅算术测试，不是配方平衡。

**联调：**E07 搬运、E08 建设、E09 维修和 E10 采矿加工共用这一账本；E12 增加保存字段，E13 展示现货／承诺区别。不能以单元测试替代真实运料结项。

## DT-E06｜有限区域路径、路线失效和工位预约

**目标／执行：**D1.1；GAME-ROBOTS；GLM 路线纯计算／跟随适配，Codex 核心运动与占用。前置 C01 的高度版本、障碍、机器人包络、工位查询。

**归属：**拟 `Navigation/` 中冻结文件；`GroundPatrol.cs`、地形提交和 Main 只由 Codex 改。

**默认方案：**先采用可消费现有高度场的有限坡度感知网格路线；这是工程假设，不是已测优胜结论。障碍按实际运动包络扩展，路线带 world_version；保留 MoveAndSlide 执行，抵达以实际位置／贴地确认。必要时短测引擎导航重建，不做通用城市交通框架。

**验收：**绕已知障碍；过窄口拒绝；坡度超界不强行通行；地形／设施变更令受影响路线失效；到站需预约且单一占用；两机窄口等待有界、可重试／退让，不能永久对顶；路径找到不等于已到达。无瞬移、直接改 Transform 假装完成。

**联调：**E07/E08/E09 共用工位预约与失败原因；导航不能维护第二套库存或调度器；C02 在实际地形和模型包络下验。

## DT-E08｜有限选址、材料建设与自举配置

**目标／执行：**D1.1；GAME-BUILD；Codex 规则，GLM 可做确定的阶段适配。前置 E02/E05/E06/E07；E09 供能与保障同批接通。

**归属：**拟 `Construction/` 当前任务需要的文件、场景自举配置；Main 与共享配置只由 Codex 写。

**步骤：**由目标登记合法位置／朝向、静态及作业占地、成本、关键组件与授权范围；整平→材料运输→实际工段→设施落成→能力注册。日照／供电状态与建成分离，太阳能夜间不能因为落成就发电。第一阶段只用现役设施，不按“一种配方一种新建筑”扩范围。

**自举输出：**正式新档仅着陆器与必要有限套件，主要永久设施玩家建。用配置账列出到首套供能／充电／加工／维护的所有投入和机器人实际耗能估计；可调初始材料／电量足以走一条安全路径，不隐藏补给。用于快速复验的预建基地明确标测试档。

**验收：**非法位置／缺不可自产组件被拒绝或进入需要条件；重复完成不重复注册能力；已施工材料不因取消全额回到仓库；已改造地形保留；不同位置与第二种支持设施走同一有限流程，不硬编码一座太阳能动画。

**联调：**A05 部件与阶段由实际状态驱动，E12 持久化工程和设施，C02 更新普通应用。

## DT-E09｜发用电、真实耗损、基础回充与维修

**目标／执行：**D1.1 即参与，D1.2 闭环；GAME-SUPPORT；Codex 关键规则，GLM 可做确定计算和状态显示。前置 E05/E06/E08 的实体／工位／能量来源。

**归属：**拟 `Support/` 指定文件；共享预约调用 E06，不建立第二套服务位占用。供电连接模型由 Codex 在合同里明确为有限、可见的合法连接及其成本，不能默认为全地图免费供电。

**步骤：**区分设备容量、当前电量和耐久；移动／有效工段按冻结配置耗能与磨损；有实际出力／能源来源才补电，分配不足不超发；正常约10%回充基线结合已知返程预算允许更早；有路、有电、接口兼容且预约成功才开始充电。维修须真实工位、物料、能源和时间，不补满电。

**验收：**暂停／退出不耗损；满电不修耐久；维修不增加电量；无电站不充电；零电或零耐久停止自主移动和工作，原因可叠加；等待服务不永久饥饿；中断原目标可接续、不重复扣料。基础安全保障不等待 E17 的环境／救援扩展。

**联调：**A06 先解决实际停靠／维修位置，A07 保证两类故障可辨；E12 保存健康／电量／排队与进度；C02 同版本验两次工作—保障—工作循环。

**目标／执行：**D1.2；GAME-WORLD/RESOURCES；Codex 原子规则，GLM 配方／有限阶段子件。前置 E05—E09 与已有地形提交；消费 A03/A04/A05。

**步骤：**已知有限铁／铜点实际到场采集，达到已定义工段后减少矿量并形成现场货物，关联地形阶段；由拖运运回。加工消耗明确输入／工位／能源，按有效模拟时间形成输出，铁矿→铁料→结构件，铜矿→铜料→线缆。可用同一现役 F02 的数据驱动配方，不擅增新设施或原料。

**联调：**E11 的缺料目标实际触发这一链，E13 显示缺口／进度，E12 保存矿量与地形同源恢复；不是“看见坑就完成采矿”。
