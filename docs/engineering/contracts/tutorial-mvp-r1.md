## 玩家结果与关卡

玩家从主页开始一个完整教学关卡，自己决定位置、朝向、建设顺序与发展方向，机器人代劳采矿、运输、加工、整平和建设。玩家看到选择的成本、供电覆盖和物流后果，能够在当前工程执行时预规划下一项；单活动目标保留，草案不接受授权、不预约或扣料。

教学顺序：认识镜头/选择与工程队 → 太阳能选址 → 充电桩建成并接线（尽早保障续航）→ 维修站建成并接线 → 加工设施建成并接线 → 选择仓储或第二太阳能，真实缺料生产并完成 → 自主建设另一个方向 → 自主在第二太阳能覆盖内建设第二充电桩并明确接线，真实使用新增仓储供料 → 教学结尾，同一世界继续经营或保存返回。首套投入、两发展与第二桩合计最多八个有限 kit；不增加配方、赠送材料、电量或耐久。使用原 `d12-firstplay-1` 数值；自然路径如不可达，先定位布局/队伍/执行问题，有具体证据再重计划。

关卡设计采用 `level-design` 的灰模先验、安全实践与关键路径检查；供电 12m、物流路径、有限库存和服务可达替代动作游戏跳跃/战斗指标。两处主动选择：多个合法首套布局的覆盖/运输差异；仓储容量及供料位置与新太阳能功率及范围的不同收益。两个发展方向都必须在正常首套后可行。迁移阶段撤去逐按钮/坐标答案，只保留规则回顾、目标与后果。

结尾来自真实世界与保存的学习历史：首套的充电/维修/加工与太阳能实际接线、采矿与配方回执、两个发展目标稳定引用、新仓储实际取货交易、第二充电桩实际连接第二太阳能且建成。不能从 UI 按钮次数、单个 Completed 字符串或太阳能总出力推结尾；夜间零出力不撤销已建立的连接能力。旧版本档导入不自动伪造已完成教学。

## 产品生命周期与 UI

主页：新游戏、继续游戏、存档、设置、退出。局内暂停菜单：继续、保存、存档、设置、返回主页、退出。离开有保存并离开、不保存离开、取消；保存失败保留当前世界与旧有效档。系统关窗采用同一离开边界。新游戏真正重置世界；不能仅重开入口后继续旧世界。三个独立新槽，槽位选择和已有档重开确认清楚；旧 d1/d11/r7 档不覆盖。

UI 用 `game-ui-ux` 的屏幕流与顶层输入归属，`godot-ui-control` 的 Control/Container/Theme、锚点、焦点与不穿透。Main 的模拟暂停和恢复屏障仍是权威，不用全局 SceneTree 暂停阻塞命令处理。菜单临时暂停与用户手动暂停分开；从设置/存档返回不会意外解除手动暂停。

常驻：当前教学目标/阶段、关键资源与功率、实际工程状态；建造方案显示完整成本/净缺口、供电来源和距离、物流后果、是否仅草案及不可提交原因。低频工程诊断离开常规工具栏，详情可回看。1280 和大窗、100/125/150% 界面或文字缩放可读，不依赖外部截图裁切。设置只提供实际生效的 UI 缩放、镜头速度和教学提示详细程度；不制作没有效果的音量/画质选项。

UI 只消费 Main 提供的只读 DTO 与排队意图，不反解析格式化字符串来计算成本/规则、不操作存档文件、不拥有教学达成。`godot-csharp` 用于实现方法，保持 Godot 4.7.2 .NET、SDK 10.0.401、TFM net8.0，不按外部技能示例降级环境。

## 供电与原 r7 缺陷

D001：新用电设施投入前展示并验证已建太阳能 12m 可达。旧合法超范围布局仍允许载入；恢复不靠拒载或免费退款。为修复既有保障设施供电，可授权有限新增太阳能及接线；已有带电加工与充电时允许该恢复目标的有限补料链，不要求尚待修复的维修站先有电。保护首套库存的守卫保留，但为具体可恢复供电目标核算剩余首套/线缆与当前现场物料，不能形成前置互锁。原触发条件必须实际恢复带电并继续后续目标；不承诺尚未实现救援的全局所有布局均可恢复。

D002：当前工程完成与首套/教学阶段达成分开；下一步派生自真实缺项、未接线与阶段需求，首套中途不提示进入发展。

D003：目标、成本、可用/在途、供电与完整原因同屏可读，字号与密度随实际窗口核，保持世界同屏与合法/非法反馈。

2026-10-12 原旧触发档恢复后运输实际两次被矿坑侧面阻挡，中心线可走但半径1.4m实体碰到42.600°陡面。主控批准局部导航修复：BoundedRoute 保公开签名与有限、只读、确定性搜索，按固定a-d三角面角及整段扫掠实体足迹核通行，规划与执行采用同一规则；保原30°寻路与35°原生上限。已卡在陡壁旁的可行动、真实贴地演员只采用有限原生运动查询筛选退让，再由 MoveAndSlide 实走续原目标，保 Destination/Station、载货、健康计费与原120s/180s时限。退让不写假坐标、扩大坡角或借重试赠资源，保存/读取/取消/重置保原业务事实。实际 blocked 副本重试卸原8矿并完成仓储、原r01恢复后续目标及正常三半径路线需独立复验；无路结果只代表未找到。

新增明确接线意图允许选择真实 facility/source；执行端重验建成类型、无现有接线、12m、单活动工程、材料与世界版本，沿现账本/生产/施工链付费。不得静默重接或免费生成电缆。
