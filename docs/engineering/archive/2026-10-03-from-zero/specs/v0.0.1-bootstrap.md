# v0.0.1｜工程启动 Spec

> 历史提案（2026-10-03；2026-10-05归档）：空工程起点与启动Spec均为当时记录。工程已经建立，本文不作现役派单合同；当前范围与状态以[产研TODO](../../../tasks/todo.md)为准。

状态：PLANNING。只有所有者指派本批后才可实施；其中主控环境核定完成后才能给工人下 READY 任务。

## 1. 起点

当前提交只有文档及文档工具，未有 Godot、C#、客户端构建或游戏测试。不得把旧 MUD 的工程和测试当已经迁入；也不得用“之前文档计划过”替代创建。

## 2. 成功定义

在指定的 Apple Silicon Mac 上，从干净检出建立并运行一个本地三维应用；它显示一个有明确名称的测试场景，能正常退出；有一项真实执行的基础测试和复现文档。

这一版不是可玩游戏，不包含采矿、生产、AI 规划、经济或全套存档。

## 3. 主控先完成的决定

记录 macOS/架构、Godot .NET 版本、.NET SDK、导出模板和编译方式，核对原生依赖。

确认是否已安装工具；新增工具先说明版本、体积、许可与用途，不能自动安装一串未知依赖或改系统配置。无设备或权限即 BLOCKED，不用 Linux/headless 替代 Metal。

创建最小 Godot 应用、独立 C# 模拟测试入口和明确项目引用方向。模拟不依赖场景；Godot 适配以后消费模拟快照。此处只建立边界，不建设完整架构平台。

具体测试框架、文件名和命令由主控核定后填回本 Spec，不能工人各选一套。

## 4. 最小工作拆分

| 任务 | 负责人 | 输出 | 依赖 |
|---|---|---|---|
| INIT-01 现场与版本核定 | 主控 | 精确版本、原生验证和必要安装申请 | 明确本批授权 |
| INIT-02 创建最小应用与引用方向 | 主控 | 可打开/编译/运行的工程、一个简单三维对象和相机 | INIT-01 |
| INIT-03 建立基础测试与日志入口 | 主控 | 测试能够真实执行；坏断言能让运行失败 | INIT-02 |
| INIT-04 整理启动说明与文件清单 | GLM | 据实际命令生成可重复 README；不发明路径 | INIT-03 |
| INIT-05 独立干净检出复验 | 独立验证者 | 实际执行记录、退出状态、已知限制 | INIT-04 |

INIT-02、03 可并行准备，但项目配置和公共文件只有主控一名写者。GLM 不负责在空仓库中自行设计整套游戏架构。

## 5. 验收列表
