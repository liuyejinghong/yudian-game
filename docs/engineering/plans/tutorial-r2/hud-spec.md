## 1. 目标与分批定位

D001 是体验问题：首屏没有让玩家建立"经营对象→状态→行动"的联系，看板混用口径（库存、供电、草案、接线并列），玩家找不到从矿到建设的路径。本方案按批呈现**真实能力**：首批重排信息与交互；批 2 的"准备材料…"、批 3 的研究入口等，在对应能力真实实现前**不画按钮、不显示入口**。

验收时玩家应能独立回答六个问题：

1. 基地现在有什么资源（哪一种口径）；
2. 当前选中的对象是什么、能做什么；
3. 正在准备什么建设计划；
4. 当前正在执行的工程是哪个、到哪一步；
5. 缺料与前置是谁在自动补、为什么阻塞；
6. 上一次操作的结果是什么。

## 2. 布局分区（主控已定）

本节布局只针对基础世界视图（对象与建设上下文），不代表全部界面；管理面板与层级见 §2.1。

- **顶部常驻细条**：只放关键当前数量：五类常用成品示例（铁料/铜料/结构件/线缆/组件套件，权威计量，库内现货口径）、当前发电（实际/s）、昼夜时刻、重要警报、暂停菜单。原矿及更多定义按分组/详情呈现，不在 HUD 上无限加列。不混入建造成本——成本只出现在建设模式卡内。物资窄窗可收入抽屉。
- **左上小目标卡**：当前目标 + 为什么（why）+ 下一步/完成条件。仅在教学进行中或存在 pin 的目标时显示，其余时候不占位。不放库存、不放工程诊断。可折叠，折叠后留一行标题。
- **右侧共享上下文栏（唯一语境栏）**：两个互斥模式——"选中对象详情"仅在有选中对象时出现，无选中则对象详情隐藏、不常驻空大板（此规则只作用于对象卡，不影响下条独立的活动工程摘要）；"准备建设：X"仅在 placement 时出现。同一时刻只呈现其一。"当前计划"卡与独立"活动工程"摘要各有自己的标题，不共用一块。
- **活动工程摘要**：建议固定在右栏底部上下文中，不随选中对象或对象卡隐藏而消失；有活动工程时独立显示一行；窄窗折叠为一行，不压世界视图。无活动工程时不占位，不显示空工程板。平时一行显示当前阶段与真实受阻提示；详情、长依赖、日志与执行者列表按需进入工程面板，不常驻整组[定位工程][详情][取消工程]等按钮；**前置采集等自动工序属于摘要内容，不作为玩家逐步操作来教学**。
- **底部紧凑工具组**：[建设][整地][基地物资][工程][科研]。未实现的能力先隐藏，不放灰色假按钮或"不可用"图标。科研按批 3 处理：系统未实现时入口隐藏；接入后入口可见，锁定节点显示前置/成本/解锁理由，仅真实 unsupported 页面隐藏。不复制 9 个镜头方向按钮；保留 WASD/拖动/滚轮/中键旋转（现有映射以代码与验收核定为准），首次提示与帮助面板提供输入表；不添加不可用的改键占位。调试诊断只在开发构建路径。

## 2.1 界面层级与打开/返回

本版分四层。这是**主控建议，待实际界面评审**。M/B 用于解释层级，未提出新增地图/背包需求；本版不新增，也不绑定不存在的机制。

| 层 | 内容 | 打开 / 关闭 |
|---|---|---|
| ① 常驻 HUD | 顶部关键数量、发电与昼夜、重要警报、暂停；目标卡（仅教学或有 pin 目标时）；底部工具组；有活动工程时的一行摘要。只保留少量入口 | 常驻（活动工程一行仅在有活动工程时出现） |
| ② 对象/现场侧栏（即 §2 右侧语境栏的对象与建设部分） | 选中矿点、机器人或设施时的简要规则、可执行动作与当前成本；placement 时的建设卡 | 点选对象或进入 placement 时临时出现；无选中或退出 placement 即隐藏。隐藏对象卡不影响独立的活动工程摘要（见 §2） |
| ③ 管理覆盖面板 | 中央大面板或近全屏，同一时刻只开一个。视图：**基地物资**（可获物资定义；按仓库位置、预留、在途、过滤；不新增玩家背包；缺数据的字段按 §12 补合同，未补前不显示）；**工程**（当前工程与真实已有的完成历史，展开依赖与真实原因；保存计划仅在批 2 真实能力可用后出现）；**科研**（仅批 3 有真实科研系统时显示，大树前置、成本、效果，锁定节点可见） | 顶部物资点击、底部按钮与未来真实快捷键共用同一入口，复用同一屏幕管理；重复触发关闭同一视图 |
| ④ 确认框 | 仅用于高代价且不可逆的操作、取消已施工工程的后果、退出未保存内容 | 预览的普通返回不弹确认；不对每次操作做双确认 |

## 2.2 管理面板的输入与暂停

- **一次只开一个主管理面板。** 资源与工程之间切换是同一覆盖层内的视图或标签切换，不叠多层互相遮挡。关闭后回到进入前的有效世界 context（选中、镜头、输入模式），并按 worldEpoch + stableID 重验（§5）。
- **焦点与穿透。** 只有顶层获得焦点并接受命令；遮罩阻断世界点击与快捷键穿透，切换面板时的输入不会产生建造。Esc 逐层关闭见 §8。
- **重复入口。** 同一按钮或快捷键再次触发即关闭同一视图，不产生多个实例；长列表返回时，在同一范围内保留标签、搜索与滚动位置。
- **暂停（主控建议，待实机评审；非所有者已接受）。** 管理覆盖层打开时临时暂停既有模拟权威（单人默认建议），复用现有菜单临时暂停与用户手动暂停分离；管理面板只持有自己的临时暂停原因，关闭只释放它，保 user/manual 原值。换标签不解除，重复暂停不叠加。接口形态以实际实现与未来合同核实为准。普通对象卡、悬停与建造预览不自动暂停，施工照常可见。实际状态改变时标记 revalidate。不用 SceneTree.pause；仅画面遮罩不证明暂停生效。
- **读档与新游戏。** worldEpoch 改变时清空临时覆盖层及其 context，已有引用按 stableID 重新投影，无效则清选；同 epoch 的菜单返回保留选址与选中。保存/读取沿用现有生命周期与故障回滚。这是对现有生命周期增加面板栈，不建新的全栈框架，完整屏幕不强制 route/world reset。
- **快捷键与焦点导航。** 只显示真实支持的操作；不承诺改键系统，也不承诺 M 地图、B 背包等机制。

## 5. 输入模式与语境切换

- 默认浏览模式：左键选对象。
- 建设/整地模式：左键**仅选址与移动预览**；占位冲突作为场址反馈显示。不隐式切对象、不提交；要看机器人等对象，先 Esc/显式退出预览，同一次点击不得既选址又选机。
- 只有明确退出/取消当前预览（Esc）才回到对象选择，并恢复进入前的对象、镜头与输入（returncontext）：恢复前按 worldEpoch + stableID 重验并重新投影；普通菜单同 epoch 返回可保 context。预览不改世界已证（L003），未保存草案无副作用。
- 活动工程摘要与语境栏分离：选中变化不使摘要消失。

## 6. 数据口径（关键约束，含已核事实）

- **Stored（库内现货）**：真实 lander/storage 库内数量。顶部条只显示它；"其中已预留"是现货子集，需真实 DTO 字段后才显示。
- **PlanningAvailable**：排除机器人携带、活跃工程占用与已付生产，可能含矿场或取消工地可回收部分；它**不等于仓库可用，也并非供料可达量，不得与 Stored 相加或互相推导**。
- **InProcess**：未完成、已付配方的预期产出；只单列为"预计产出"，不计入已有量。**不写"总库存 = 可用 + 预留 + 在途 + 在制"之类的恒等式**。
- 点击顶部物资：按物理位置列出仓储 / 机器人携带 / 工地现场 / 加工批次。
- "可用于此计划"不是现成 PlanningAvailable：首批由 authority 的 ReadBuildPlan 按与提交**同资格**筛算；UI 不自行减 reserved、不解析中文拒因字符串、不算配方推导。
- 电力：现仅太阳能 sum 的 currentGeneration/s（单位仍为 /s），无需求/储电/净额——这些数字**不显示、不虚构换算 W**。首版显示发电/s + 设施真实连接状态（见 §7）；扩到净供需须待结构化 power source / connected / demand allocated / grid scope DTO 加测试冻结，并按真实连接网络的供能范围同口径计算；无 stationary battery 就不显示储能。

## 7. 对象详情与合法动作

| 对象 | 首批显示 | 后续批次（实现后才显示入口） |
|---|---|---|
| 矿点 | 名称/剩余储量/位置/能加工成什么；物料链与需前置设施（数据缺，工程补写，见 §12；选中能力缺，见 §11） | 批 2 "准备材料…"：产物数量、目标仓储、成本与权限，由机器人分工执行；不强迫选择筑垒采矿 |
| 机器人 | 健康/分工/当前目标/[定位]；电量与耐久分开显示 | 逐机维修不做成免费一键满血 |
| 设施 | 已建成 vs 当前运行供能状态分开显示；connected（Source/ServiceConnected）与运行供能状态分别显示——现值真实含义须对应具体 producer（现 Powered≈Built 且日照），分配明细需 DTO，不得把运行状态标成"剩余分配"；**夜间发电 0/s 不等于"未接电"**；"连接电源"只对合法未连接 target 可用（来源可达 + 线缆成本 + 确认 → 真实 construction），不做全局接线，也不因夜间 0/s 要求付费重接。首批状态用已有真实值：已连接 / 等待日照 / 未连接，配发电/s | 供电分配明细（补 DTO 后） |
| 地形 | 仅在真实补 DTO 后显示边界高差/目标基底/用途/代价/受限原因；不把高程 0 当所有场址基准 | 整平作为可见代价收益的经营决策 |

教学按"对象 → 动作 → 反馈"引导；撤提示后玩家按同一规则独立完成第二项工程。

## 8. 交互规则

- Esc 逐层，每次只弹出最上层：子详情或确认框 → 管理面板（回进入前的有效世界 context）→ 建造预览（若有）→ 回世界；世界态 Esc 开暂停菜单。从确认框拒绝 Esc 只取消该框，不自动删除活动目标。**Esc 不取消正式工程**。
- Enter 只确认当前焦点按钮，并防 click-through；UI 控件抢 pointer 不穿透，纯装饰元素设 IGNORE。
- hover tooltip 只做解释，不偷选择、不切换当前模式。
- 双确认只做一次；确认时 authority 以实际版本号 revalidate。
- 无料/无目标/空选时给出解释与真实可行动作（fallback），可附工具入口（如打开帮助/建设）；不留死按钮。

## 9. 响应式与平台

- 适配 1280x800、1920x1080、Mac 16:10；缩放 100/125/150%。
- 单语境栏宽度设上限；容器用 anchor/Container 布局，不用绝对坐标。

## 13. 验收

- 验收分两轨：**固定回归 + 新玩家盲测**；两轨均为实施后的测试计划，**本轮未运行**。
- 六问题盲测：新玩家不求助能独立回答第 1 节六问。
- 固定口径线：顶部数字与账本实物一致（账实相符），不是各口径 availability 之和；测试不做恒等式断言。
- 电力边界：已接线太阳能夜间 0/s 显示"等待日照"，不判"未接电"；连接按钮仅对未连接 target 合法。
- 布局边界：1280+高倍率下阻塞与主按钮可见、世界可选址。
- 回归链：空选、双确认、Esc 逐层、同 epoch 菜单返回保 context；**任意加载（同槽或跨档）、新游戏或 epoch 变更**清临时预览，旧引用不直接复用——按 worldEpoch + stableID 重验，有效对象重新解析投影，无效清选并回当前工程摘要；刷新/保存/恢复后工程与摘要不丢，但不承诺所有选中值永久保留。
- 覆盖层回归（管理面板）：空态与长列表的打开/关闭；重复快捷键只关闭同一视图；焦点只在顶层；遮罩不穿透（不产生建造）；暂停恢复（只释放面板临时暂停，保 user/manual 原值）；epoch 失效与关键操作同帧重验。与 D001 新玩家盲测的验收口径保持一致，本项不替代盲测。
