## 固定起点与证据

读取本批 [implementation-contract.md](implementation-contract.md)、[task-graph.md](task-graph.md) 与候选交付身份记录。核源码 commit、候选主包和验收入口的 PCK/程序集/资源一致性，使用独立新私有槽根与设置根；禁止改正式槽或旧包，不复用旧 E 编号。

普通候选为双击玩家入口。验收入口应由正常 launch 配置设置既有 `YUDIAN_PLAYER_GUI_TEST=1` 与绝对私有 `YUDIAN_TUTORIAL_TEST_ROOT` / `YUDIAN_PLAYER_TEST_SAVE`，不启用任何 SELF_TEST/自动driver/TimeScale/健康或物料作弊。不得通过没有私有环境的重新绑定意外启动正式入口。保存退出后只查进程，不调用已退 app 的 getApp/getAX 以免自动重启。

只定向观察自有测试窗口。使用 Codex 已有正常 computer use 支持路径，保持所有者继续在其他应用工作，不争系统鼠标/焦点，不切可信宿主或伪造身份绕拒绝。tool success 不是游戏完成；动作后回读新鲜画面、目标反馈与实际日志。若新鲜窗口捕获失败，两次失败保原件、报告工具阻断，不盲点、不给游戏判死锁。

证据分成截图/录像、动作时间线、实际日志、存档只读核验及脱敏报告。每条记预期、实际、PASS/FAIL/BLOCKED/NOT_RUN以及新E编号。公开仓库不放私人路径、正式玩家数据或整个桌面截图；原始私有档留验收工作区。

## 1. 真实入口与经营对象

1. 私有空槽从主页→新游戏→开始，核新世界初始资源和12机器人，保原教学达成条件。
2. 浏览态点铁/铜矿、机器人、着陆器及已建设施：名称/储量/真实配方链、分工/目标/携带、电量与耐久、建成/连接/日照运行分开。空点无常驻空大板；选择不下达工程。
3. 矿点说明引向“选择建设目标，由机器人自动准备缺料”，不要求选筑垒逐机采矿。资源物料链有真实目录数据；视觉引用与游戏已接入资源一致。
4. 顶栏只库内现货，物资详情将仓库、预留、机器人携带、现场与已付加工预计产出分开；对照只读私有保存的真实容器/预留/任务，不能跨口径求和。spend容器不是库存。

## 2. 预览、当前工程与因果链

1. 建设/整地模式左键仅选址；点机器人或矿点仍是场址反馈，不意外切对象，不提交。Esc一次退出预览，恢复进入前有效对象/镜头；不取消正式工程。
2. 建设卡给完整成本、此计划资格量/缺口、收益、场址/供电拒因；1280窄窗高缩放时当前阻塞与主按钮仍可见。预览多点/非法重叠/旋转不扣料、不登记工程。
3. 正常完成首套太阳能、充电、维修、加工和真实付费接线，再选择缺料建设。操作前记完整成本与资格缺口，点击“开始建造”授权一次；双击/Enter重触不建第二目标。
4. 实际观察采矿→输入运输→加工→输出运输→筹料齐备→整地（实际需要时）→施工→建成。每一步使用真实目标/任务ID、阶段、原因与有效分母；运输无伪百分比。保真实电/耐久/仓库/物料消耗，不赠料或跳过前置。
5. 执行中选择机器人、矿点、另一建设预览或接线面板，当前工程摘要始终指向原活动目标；草案拒因不能成为原工程原因。目标卡只讲当前教学对象、为什么和下一步，自动前置不是新玩家按钮。
6. 建成用电设施后明确选 target/source，列真实线缆成本/12m范围，真实运输施工。夜间0/s而已有连接显示等待日照，无重复付费接线；待自然日照后供能恢复。不把发电/s换算成未实现的W/净余电/储能。

## 3. 管理层、焦点与返回

1. 顶栏物资与底部基地物资打开同一层；物资/工程标签切换不叠层。相同入口再次触发关闭；空态、长列表/筛选、同范围滚动返回可用。
2. 进入前记镜头、选中对象/建设模式与世界状态。管理期间只顶层按钮/输入接受焦点，遮罩点击、WASD/QE/F/滚轮/Enter不穿透世界，不隐式选址/建造；有搜索输入时键入只作用于搜索。
3. 未手动暂停时，打开管理观察世界钟、机器人位置、健康、工作进度、Waiting与物料不变；关闭后自然继续。手动暂停时再开关管理，关闭仍保持手动暂停。标签切换不释放管理临停，普通对象/预览不自动暂停。
4. 从物资预留跳相关工程在同层详情；关闭后回进入前有效世界context，按epoch+stableID重解析，无旧对象引用。
5. Esc每次一层：确认或子详情→管理→预览→暂停菜单；Esc不取消工程。取消必须明确目标和后果，再确认只取消该目标。预开工取消释放未用预留；运输/已改地后取消保实际货物和地形，不瞬间返料。已完成或切世界的旧确认不可取消另一个工程。
6. 正常暂停/设置返回同epoch保context；同槽读档、跨槽读档、新游戏或loading开始清临时预览/管理context，失败rollback后也不复用旧草案。活动工程由当前世界重投影，摘要/实际物料不丢。
