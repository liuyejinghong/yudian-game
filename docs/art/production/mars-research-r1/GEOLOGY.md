# 火星地质与资源外观依据

研究日期：2026-10-07。用途：约束本轮自然地表和六类已有资源的美术候选；不改变 simulation ID、库存语义或配方。

**结论：游戏“铁矿／铜矿”是资源链名称，不能直接翻译成火星地表上裸露的铁块／铜块。** 铁矿优先对应“候选含铁玄武质原料”，表现为岩石；铜已有局部元素增强证据，但资源来源、可用富集与加工方式仍待证据。资源类别由标识、容器和作业反馈表达，不用捏造铜绿矿脉承担辨识。

## 证据怎么用

- **事实**：仪器检测、探测器影像元数据和原研究结论。每项只覆盖其地点、样本与方法。
- **推论**：依据事实选视觉候选；不是矿床发现，也不是全部火星的共同地质。
- **游戏抽象**：资源链、单位产量、分类标识与工业产品。保留现有系统，但不能以这些设定反证火星地质。

普通照片能提供粒度外观、层理、裂隙、块状／片状、尘覆程度、侵蚀形态和相对颜色；矿物种类、元素含量通常需要对应仪器。CRISM 的矿物彩图是可见／红外光谱叠加结果，例如蓝色代表辉石、红色代表橄榄石，不能当成岩石实际配色。[NASA：CRISM 方法与彩图说明](https://www.nasa.gov/missions/mars-reconnaissance-orbiter/nasa-retires-mineral-mapping-instrument-on-mars-orbiter/)

CheMin 使用粉末样本的 X 射线衍射辨认矿物；ChemCam 的 LIBS 分析元素。看到铁或铜的元素信号，不等于确认某一矿物，更不等于工业可采矿床。品位、连续性、规模、开采条件与加工回收条件仍需额外证据；这是本轮证据边界，不是宣称火星没有矿床。[NASA：CheMin](https://www.nasa.gov/missions/mars-science-laboratory/curiosity-rover/what-is-the-chemistry-and-mineralogy-instrument/)、[Goetz 等，2023，铜检测原研究](https://doi.org/10.1029/2021JE007101)

## 地质候选及地点限制

| 材料／岩性 | 已证事实与地点 | 美术候选（推论） | 不能外推的部分 |
| --- | --- | --- | --- |
| 风化层、尘、沙、碎岩 | 风化层是破碎岩石与尘的集合；Gale 的 Rocknest 风成样本含晶质与 X 射线非晶组分，晶质组分有斜长石、橄榄石、辉石等，具玄武质特征。[JPL 定义](https://www.jpl.nasa.gov/images/pia24728-watson-views-foux/)、[Blake 等，2013，§Mineralogy／表1](https://mars.nasa.gov/files/msl/Science-2013-Blake-.pdf) | 细尘覆盖颗粒与碎岩，沙纹／颗粒粗细可变；局部暴露暗色原料 | 不能把 Rocknest 晶质归一化比例当成全样本或全火星成分；“土”不暗示地球有机表土 |
| 玄武质岩／含铁硅酸盐 | Rocknest 橄榄石及辉石具 Ca–Fe–Mg 成分；Jezero 的 Máaz 与 Séítah 已确认火成来源，分别涉及熔岩流候选及富橄榄石堆晶岩。[Blake 等，2013](https://mars.nasa.gov/files/msl/Science-2013-Blake-.pdf)、[Sun 等，2023，NTRS 摘要](https://ntrs.nasa.gov/citations/20230016431) | 暗灰／灰褐、尘覆、棱角破面、局部颗粒；含铁原料采用岩石而非金属光泽 | 富橄榄石堆晶岩不统称普通玄武岩；含铁不是天然纯铁，照片不能量品位 |
| 橄榄石／辉石 | Jezero 局部橄榄石晶粒由磨蚀面、化学与 PIXL 测量确认，约1–3毫米；不是大颗绿色宝石。[JPL：Jezero 2022](https://www.jpl.nasa.gov/news/nasas-perseverance-makes-new-discoveries-in-mars-jezero-crater/) | 近景小颗粒、粗糙晶粒与基质关系；正常 RTS 视距合并成岩块表面 | 不照搬光谱彩图颜色；晶粒尺度不任意放大 |
| 铁氧化物／氧羟化物 | CRISM 检测到赤铁矿等；2025 ESA 介绍的实验与轨道资料联合研究发现水合氧化铁 ferrihydrite 与玄武岩混合更匹配火星红尘。[NASA：CRISM](https://www.nasa.gov/missions/mars-reconnaissance-orbiter/nasa-retires-mineral-mapping-instrument-on-mars-orbiter/)、[ESA：红尘研究](https://www.esa.int/Science_Exploration/Space_Science/Mars_Express/Have_we_been_wrong_about_why_Mars_is_red) | 锈红／赭色细尘或局部涂层，可覆盖不同岩性 | 不把所有红色都认作纯赤铁矿或铁矿点；ferrihydrite 匹配结果不是每粒尘的直接鉴定 |
| 泥岩、砂岩 | Yellowknife Bay 的 Sheepbed 为细粒沉积；Meridiani 的 Wopmay 为富硫酸盐砂岩；Gale 硫酸盐区照片亦见暗色岩块和灰色砂岩盖层残余。[JPL：两种水环境](https://www.jpl.nasa.gov/images/pia16833-two-different-aqueous-environments/)、[NASA：2022全景图注](https://science.nasa.gov/resource/curiositys-view-of-sulfate-bearing-region-and-streambed-rocks/) | 薄层、板状碎块、层阶、侵蚀轮廓；泥岩与砂岩按参考地点分组 | 暗色不自动等于玄武岩，片状不自动等于金属矿；两地点水化学不能混为一种 |
| 硫酸盐／黏土 | Sheepbed 裂隙中硫酸盐充填有多仪器支持；OMEGA／CRISM 水成矿物地图记录不同区域黏土与盐类。[JPL：Sheepbed](https://www.jpl.nasa.gov/images/pia16833-two-different-aqueous-environments/)、[ESA：水成矿物地图](https://www.esa.int/Science_Exploration/Space_Science/Mars_Express/New_water_map_of_Mars_will_prove_invaluable_for_future_exploration) | 特定地点可用细浅色裂隙脉、层状露头；不要铺满全部地表 | 白色裂隙只能作为形态候选，不能凭颜色指定石膏；硫酸盐不是单质硫 |
| 碳酸盐 | Jezero 火成岩保存局部次生碳酸盐等蚀变；2025 Gale 三个钻孔在 Mount Sharp 富硫酸盐层确认菱铁矿，轨道近红外可能被其他矿物遮蔽。[Sun 等，2023](https://ntrs.nasa.gov/citations/20230016431)、[JPL：菱铁矿](https://www.jpl.nasa.gov/news/nasas-curiosity-rover-may-have-solved-mars-missing-carbonate-mystery/) | 保留母岩层理／裂隙；有地点证据再选次生矿物细节 | 不能把火星画成普遍白色石灰岩；未有轨道信号不必等于不存在，地表颜色也不能确认碳酸盐 |

## 六类游戏材料的命名与视觉候选

本表是美术说明建议，原游戏材料名称照旧。不要据此重命名 ID 或实现新的资源链。

| 现有游戏名称 | 来源岩石／矿物解释 | 视觉候选 | 证据与限制 |
| --- | --- | --- | --- |
| 铁矿 | **候选含铁玄武质原料**；含铁硅酸盐与氧化物为依据，不锁死某一矿物配比 | 灰黑／灰褐尘覆碎岩，棱角与破面；类别标识区分 | Rocknest 与 Jezero 支持这种材料候选；工业可采性、提炼效率尚未验证。[Blake 等](https://mars.nasa.gov/files/msl/Science-2013-Blake-.pdf)、[Sun 等](https://ntrs.nasa.gov/citations/20230016431) |
| 铜矿 | **含铜原料（来源与富集工艺待证据）**；若需现实母岩候选，先参考 Gale 已检测局部铜增强的泥岩／砂岩 | 暂用普通沉积岩碎块／有标识的原料容器；局部暗色侵蚀边缘仅作地点候选 | ChemCam 确认局部 Cu 增强，不确认裸铜、铜绿或矿床。游戏采点与稳定供应属于抽象。[Goetz 等，§3–4、图7–8](https://doi.org/10.1029/2021JE007101) |
| 铁料 | 人工加工产品；来源链沿用游戏设定 | 规则坯件／捆扎或装箱物，工业表面 | 形状属于游戏工业设计；天然火星影像不为其背书 |
| 铜料 | 人工加工产品；来源与回收方式未核验 | 规则坯件／封装材料；铜色只用于产品候选 | 不反推天然岩石应露出金属铜，不宣称真实流程已成立 |
| 结构件 | 工业构件；不是天然矿物 | 有连接／装配语义的规则零件，复用已有容器 | 不新增合金配方、工艺或产量 |
| 线缆 | 工业制品；不是天然矿石 | 绝缘外皮、卷束与端部识别 | 铜导体可由工业产品语义表达，不需要地表铜绿提示 |

## 铜证据的强弱

**强：元素检测。** Goetz 等统计 Curiosity 前3007个火星日、约24公里路线上10处铜增强区域，包含 Kimberley 的富锰砂岩、Glen Torridon 的富镁泥岩与富铁砂岩。**弱：矿床来源推论。** 作者讨论 Gale 北方富铜源区及后期流体搬运，未给出已探明矿床的储量、连续性或工业回收方案。**本轮未证：**黄铜矿、孔雀石、蓝铜矿或天然铜构成游戏采点。[原研究摘要、§2与§4](https://doi.org/10.1029/2021JE007101)

原研究图8的富铜目标可为暗色、侵蚀、结核状外观，并非统一铜绿。凭绿色、亮斑或金属感无法替代 LIBS 或矿物鉴定；其他着色、光照、图像处理也需要排除。铜色块和铜绿脉若用于地表，只能明确标为未经地质确认的游戏符号，本轮不建议采用。[Goetz 等，图8与对应讨论](https://doi.org/10.1029/2021JE007101)
