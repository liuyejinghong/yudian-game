## 2. ART-01 构图简报

用途：产品概念与建设痕迹比较，不用于宣传真实游戏截图。建议横向 3:2 或 16:9 设计板，上下或左右两幅，同一相机、太阳方向、场景边界与地标。

视觉：有体积的民用航天工业、浅色模块化外壳、深灰功能结构、蓝黑光伏面板、少量克制暖色识别；火星地面赭红与岩灰。正常白昼，画面清楚，非落日海报、非战争、非玩具、非像素。

景别：RTS 斜俯视普通指挥距离，足以观察完整小型工程区，不用低机位巨构建筑掩盖正常游戏尺度。

共同内容：着陆器、已有阵列、加工/仓储与补能维修相关设施、三类非人形机器人、待开发坡地和矿点。不画炮塔/机甲兵，不强迫加入穹顶城市或完整道路经济。

前：保留已有基础设施，拟建位置是带岩石的小土坡，矿点尚未明显开挖；必要机器人与物资可以待命。不是只有空白荒地与一座成熟城市的失衡比较。

后：同一块土坡被整平，清楚可见切坡边界与压实/施工地面，新阵列就位，矿点露出开挖层与凹口。已有设施和地标保持位置；机器人分别采运、施工或补能，轨迹与任务可读。地表变化不是仅画轮胎印。

版面可使用简短标签：`余电 / YUDIAN`、`原始场地`、`建设之后`、`概念，非实机`。不要加入虚假的 FPS、余额、进度或已经通过测试的印章。

此图可以固定美术方向，但不能固定真实碰撞、导航、产矿或维修规则；这些由技术原型核验。

## 3. 图片之后的生产门槛

选定方向后才做少量三维样件：一台驮运、太阳能和加工设施、坡地/矿点状态。共享尺度、锚点、材质和动画接口由强模型主控与技术首件确定，GLM 可以整理元数据或按成功样例执行有界扩展。

概念 → 设计参考 → 网格/材质/动画/碰撞/LOD → 导入 → 实机。不能把任何一步省略后仍声称生产资产已完成。

固定视角也不意味着“某个角度好看即可”：检查所有允许镜头范围、正常缩放、场景遮挡与细小结构闪烁。

## 5. 评审问题与停止条件

先看：对象能否辨认、工作能否理解、改造位置能否找出、长时间观察是否舒服。材质更精细不能代替前三项。

ART-01 不符合预期：在选定参考方向内局部调整，不批量制作。三维样件不达性能或可读性：优先修轮廓、模型/材质组织和局部配置，不删除真实地表或提高最低硬件来掩盖问题。

所有者确认概念后，也只有相关视觉决定变为 SELECTED；并非所有产品与技术参数自动冻结。
